## ✨ 主な機能

### 📥 ダウンロードとファイル処理
- ⚡ **M3U8 セグメントダウンロードと暗号解読**: TS セグメントのマルチスレッド並行ダウンロード、AES-128-CBC 自動復号、レジューム（中断再開）に対応。
- 🌊 **Streamtape ストリーミング**: Streamtape の難読化スクリプトを解読し、ディスクへストリーミング書き込み。

### 🛡️ サイトへの適応とスクレイピング対策への対応
- 🔒 **Cloudflare認証と状態管理**: Cloudflareの認証情報を取得・管理する機能を内蔵。無効な認証情報は自動的に破棄し、再認証を促します。
- 🌐 **スマートプロキシ自動認識**: OSの HTTP / SOCKS5 プロキシ設定を自動的に認識・適用（Clash、Shadowsocks などのプロキシツールに完全対応）。
- 🔄 **MissAVミラーサイトの自動切り替え**: メインのドメインへの接続に失敗した場合、利用可能なミラードメインを自動的に検出し、切り替えます。
- ⚙️ **SupJavの複数ソース対応**: 複数のソース（`TV` / `FST` / `VOE` / `ST`）間でのサーバー検出と自動フェイルオーバーをサポート。動画セグメントから、偽装されたPNG画像ヘッダーデータを自動的に除去します。
- 🎬 **予告編（トレイラー）の自動フィルタリング**: 短いプレビュー動画（600秒未満）を自動的にスキップし、本編動画のソースへ切り替えます。

### 🎨 インターフェースとインタラクション
- 🪶 **極小軽量フットプリント**: バイナリサイズは僅か **約 10 MB+** 程度。従来の Electron と比較してメモリ消費量を **80% 以上削減** し、ミリ秒単位の高速起動を実現。
- 📐 **レスポンシブ・グリッドレイアウト**: ウィンドウサイズに応じて列数を自動調整し、大画面でのカバー画像の引き伸ばしやぼやけ、小画面でのテキストの窮屈さを防ぎます。
- 👁️ **カード・ホバープレビュー**: カードにマウスカーソルを合わせると、動画のプレビュークリップを読み込んで表示します。
- 📋 **一括タスク制御とデュアルゾーン管理**: ホバー時にツールチップが表示される、コンパクトな2段構成のダウンロードキューレイアウトを採用。「すべて選択」、複数選択、および一括操作（開始、一時停止、キャンセル、ワンクリックでの履歴削除）に対応しています。
- 🎨 **フラットデザインとマルチテーマ対応**: 現代的なフラットデザイン仕様を採用し、ダークモードやライトモードなどのテーマを内蔵。シームレスかつリアルタイムに切り替え可能です。
- 📊 **ディスクストレージ分析**: 対象ドライブの総容量、空き容量、およびダウンロード済みファイルが占めるストレージの割合を表示します。
- 🌐 **多言語対応**: 繁体字中国語、簡体字中国語、英語、日本語のインターフェースに加え、多言語の動画タイトル表示にも対応しています。

## 📦 どのバージョンをダウンロードすべきですか？

お使いの OS および CPU アーキテクチャに合わせて、適切な Release インストーラーまたはポータブル（免インストール）ファイルを選択してください：

| OS | アーキテクチャ | ファイル形式 / ファイル名例 | 説明・使用方法 |
| :--- | :--- | :--- | :--- |
| **Windows** | x64 (64ビット) | `avdl_*_x64-setup.exe` / `.msi` | **インストーラー版**: ダブルクリックしてセットアップウィザードに従いインストール |
| | | `AVDL_*_windows_x64.exe` | **ポータブル版（免インストール）**: ダブルクリックで直接実行可能 |
| **macOS** | Apple Silicon (arm64, Mシリーズ) | `AVDL_*_mac_arm64.zip` | **ポータブル zip**: 解凍後、`avdl.app` をアプリケーションフォルダに移動して使用<br>*(初回起動時にアクセス拒否等のブロックが発生した場合は、下記の macOS トラブルシューティングを参照)* |
| | | `avdl_*.dmg` | **DMG インストーラー**: DMG をマウントし、アイコンを Applications フォルダにドラッグ＆ドロップ |
| **Linux** | x64 (64ビット) | `AVDL_*_linux_x64.tar.gz` | **ポータブルアーカイブ**: 解凍して抽出された `avdl` 実行ファイルを直接実行 |
| | | `avdl_*.AppImage` / `.deb` | **標準パッケージ**: AppImage に実行権限を付与して実行、`.deb` は Debian/Ubuntu 向け |

## 🍎 macOS 使用説明とトラブルシューティング

macOS 上でビルドされた `.app` または単一バイナリを実行する際、本ソフトウェアはオープンソースの未署名アプリケーションです。初回起動時に Gatekeeper によってブロックされた場合は、ターミナルで以下のコマンドを実行してください：

```bash
# アプリケーション包の属性解除
xattr -cr /Applications/avdl.app

# 単一バイナリの属性解除
xattr -cr ./avdl
```
