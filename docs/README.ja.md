# AVDL - 動画ダウンローダー

🌐 Language: [简体中文](../README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | **日本語**

Tauri v2、React、Rust で構築された高性能デスクトップ動画ダウンローダー＆ブラウザー。JableTV、MissAV、SupJav に対応。

## ✨ 主な機能

### 📥 ダウンロードとファイル処理
- ⚡ **M3U8 セグメントダウンロードと暗号解読**: TS セグメントのマルチスレッド並行ダウンロード、AES-128-CBC 自動復号、レジューム（中断再開）に対応。
- ⏩ **Faststart シーク最適化**: MP4 結合時に `-movflags +faststart` パラメーターを追加し、キーフレームインデックス位置を最適化。生成された MP4 の即時シーク・再生が可能。
- 🌊 **Streamtape ストリーミング**: Streamtape の難読化スクリプトを解読し、ディスクへストリーミング書き込み。

### 🛡️ サイト適応とクローラー対策対応
- 🔒 **Cloudflare 認証と状態検知**: 組み込み認証ウィンドウで `cf_clearance` 資格情報を取得・管理。`403 Forbidden` 応答時に無効な資格情報を自動削除し再認証を案内。
- 🔄 **MissAV ミラー自動切り替え**: 主ドメインへの接続失敗時に利用可能なミラーアクティブドメインへ自動切り替え。
- 🔗 **Referer リファラー偽装**: リクエスト時に適切な `Referer` ヘッダーを付与し、プレビューやセグメントのブロックを回避。
- ⚙️ **SupJav マルチサーバー切り替え**: `TV` / `FST` / `VOE` / `ST` 複数サーバーを自動検証・フォールバック。TS セグメント内の擬似 PNG ヘッダーを自動削除。
- 🎬 **予告編自動フィルター**: M3U8 の総再生時間を解析し、600秒（10分）未満の短編予告動画をスキップして本編動画サーバーへ自動切替。

### 🎨 UI・ユーザー体験
- 📐 **レスポンシブグリッドレイアウト**: CSS Grid `auto-fill`（最小幅 240px）を採用し、ウィンドウサイズに応じて列数を自動調整。
- 👁️ **ホバー動画プレビュー**: サムネイルホバー時にプレビュー動画を読み込み、メモリ内 Blob URL で再生。
- 📋 **一括タスクコントロールと2セクション管理**: ダウンロードキューを「進行中」と「完了済み」の2つの領域に分類表示。2行コンパクトレイアウト、全選択・多重選択、一括開始・一時停止・キャンセル・履歴消去に対応。
- 🎨 **マルチテーマ切り替え対応**: daisyUI の多様なテーマ外観（ダークモード・ライトモード含む）を内蔵し、ワンクリックでシームレス切り替えに対応。
- 📊 **ディスクストレージ分析**: 保存先パーティションの全容量、空き容量、ダウンロードファイル占有率を可視化表示。
- 🌐 **多言語対応**: 繁体字中国語、簡体字中国語、英語、日本語に対応。

## 🛠️ 技術スタック

- 🖥️ **デスクトップフレームワーク**: Tauri v2
- ⚛️ **フロントエンド**: React 19, TypeScript, Vite
- 🎨 **UI・スタイル**: Tailwind CSS, daisyUI, Lucide React
- 🐻 **状態管理**: Zustand
- 🦀 **バックエンド**: Rust
- 🌐 **ネットワーク・暗号処理**: `reqwest` / `wreq`, `scraper`, `aes` / `cbc`
- 🎞️ **動画結合**: FFmpeg（システム PATH に `ffmpeg` が必要）

## 🚀 開発とビルド

### 📋 動作環境
- Node.js (v18+)
- Rust (1.75+)
- FFmpeg

### 📦 開発・パッケージング

1. **依存関係のインストール**
   ```bash
   npm install
   ```

2. **開発サーバーの起動**
   ```bash
   npm run tauri dev
   ```

3. **実行ファイルのビルド**
   ```bash
   npm run tauri build
   ```

## 🍎 macOS 使用説明とトラブルシューティング

macOS 上でビルドされた `.app` または単一バイナリを実行する際、本ソフトウェアはオープンソースの未署名アプリケーションです。初回起動時に Gatekeeper によってブロックされた場合は、ターミナルで以下のコマンドを実行してください：

```bash
# アプリケーション包の属性解除
xattr -cr /Applications/avdl.app

# 単一バイナリの属性解除
xattr -cr ./avdl
```
